# MATRUBHUMI-CMS

Single repository holding the whole Matrubhoomi platform.

## Structure

| Folder | What it is |
| --- | --- |
| `matrubhoomi-hrms/` | Next.js web front end (HRMS + Sales CMS) |
| `matrubhoomi-hrms-backend/` | Node.js / Express API and data models |
| `matrubhoomi-field-app/` | Android field app (Kotlin, Jetpack Compose) |

Each folder keeps its own `README.md`, `CLAUDE.md` and `.gitignore`; see those
for per-project setup and run instructions.
